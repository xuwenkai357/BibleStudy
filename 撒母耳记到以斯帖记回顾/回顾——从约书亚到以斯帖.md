# 回顾——旧约历史书（约书亚记至以斯帖记）

旧约历史书共十二卷——从约书亚记到以斯帖记，它是摩西五经之后，救赎故事的延续与展开。在摩西五经我们看到神赐下应许，而这段历史书则是让我们看到应许如何一步步奇妙的被推进，以及以色列百姓经历考验、失落与保守。

当我们追溯以色列民族近千年的历史时，这段历史始于约书亚带领以色列人攻取迦南地，到被掳巴比伦归回，意味着旧约时代即将结束。

然而，在这一进程中，它往往太容易给人造成极大的误解，只看到一连串的战争、王朝兴衰、政治斗争，看到上帝残暴，毫无仁慈。当我们开始学习这段旧约历史时，是否能透过这段历史，拨开云雾，真正看到这些历史背后上帝的心意是什么？

在接下来让我们继续一起回顾：如果摩西五经是救赎故事的起点——神作出应许，拣选亚伯拉罕，从埃及救出祂的百姓，在西奈山立约，赐下律法——那么历史书就是救赎故事的展开：神的应许如何一步步成就、又如何因人的悖逆而遭遇波折，最终指向那一位真正的君王，唯一的救主。

历史书让我们看到什么呢？神的信实与人的败坏。以色列人纵然失信，神却总是信实的。历史书也清楚表明，顺服蒙福，悖逆遭祸受咒诅，这一守约的原则。

在摩西五经我们以「约」作为关键词，它同样可以延伸至历史书。

**关键词：约**（应许的成就与持守——从亚伯拉罕之约到大卫之约）

**核心经文：**

```text
你的国位也必坚定，直到永远。我要作他的父，他要作我的子。
（撒母耳记下 7:16 和合本）
```

从约书亚记开始，以色列人在约书亚的带领下进入应许之地，神信实地实现了他对亚伯拉罕、以撒、雅各的应许。然而，百姓在迦南地经历了信与不信的争战，士师时代的循环，最终要求立王。神赐给他们扫罗、大卫、所罗门，建立大卫之约，应许弥赛亚从大卫后裔而出。

但因着列王的悖逆，王国分裂，最终北国以色列和南国犹大都先后被掳。在被掳中，神没有丢弃他的百姓，借着以斯拉、尼希米带领余民归回，重建圣殿与城墙，并以斯帖记显明神在普世历史中对他子民的保守。这是神在人不断的失败——失约中，仍然信实守约的心意，由此指向那终极救赎者——主耶稣基督。

## 一、征服与士师时期（约书亚记、士师记、路得记）

### 《约书亚记》——进入应许之地（得着应许）

- **关键词**：土地、征战、安息
- **主题**：神信实守约，带信靠祂的以色列人进入了迦南地、征服了迦南地，并且进入了安息。

**核心经文：**

```text
凡你们脚掌所踏之地，我都照着我所应许摩西的话赐给你们了。
（书 1:3）
```

```text
他们回答约书亚说：“你所吩咐我们行的，我们都必行；你所差遣我们去的，我们都必去。我们从前在一切事上怎样听从摩西，现在也必照样听从你。惟愿耶和华你的神与你同在，像与摩西同在一样。”
（书 1:16-17）
```

约书亚记是救恩历史的全新篇章——不再是关于漂流，而是关于承接与得着。这卷书的核心不再是我们会不会失败，而是神已经为我们得胜，好叫我们凭信心去领受。

摩西死后，神呼召约书亚起来，带领百姓过约旦河、进入迦南。约书亚这个名字原意是「耶和华是拯救」——他预表了那一位真正的拯救者耶稣（耶稣正是约书亚的希腊文形式）。

### 《士师记》——没有王

- **关键词**：循环、悖逆、拯救
- **主题**：离开神带来败坏与压迫，神的百姓需要一位完全的拯救者方能保护这土地和得到安息。

**核心经文：**

```text
那时以色列中没有王，各人任意而行。
（士师记 21:25 和合本）
```

士师记描绘了约书亚死后，以色列人陷入拜偶像、道德沦丧的黑暗时代。他们离弃神，被仇敌欺压；在苦难中呼求神，神就兴起士师拯救他们。但士师死后，他们又犯罪远离神。这卷书暴露了人内心的罪恶与对救赎主的迫切需要。

士师记呈现了一个令人心痛的循环模式：以色列人犯罪—神允许外敌压迫—百姓悔改呼求—神兴起士师拯救—恢复和平—再次犯罪。这一循环在整卷经文中一共重复了九次。我们也要注意，这九次循环是不一样的，它是越来越糟糕的循环。随着整卷书的进展，每一个士师所获得的胜利也是越来越小。

一句话总结这卷书：「那时以色列中没有王，各人任意而行。」（士 21:25）摩西和约书亚生前早已预言了这一幕——人若离开神，在罪中只会越陷越深。人靠自己根本没有办法对付自己的罪。每一次拯救之后，他们又回到老路上。我们需要的不只是一个又一个的士师，而是一位永远的君王、一位真正的救主，祂完全顺服，完全得胜，永远掌权。

### 《路得记》——伏笔应许中的王

- **关键词**：跟随、忠诚
- **主题**：神奇妙的救赎计划，埋下种子。

**核心经文：**

```text
不要催我回去不跟随你。你往哪里去，我也往那里去；你在哪里住宿，我也在那里住宿；你的国就是我的国，你的神就是我的神。
（得 1:16）
```

```text
于是，波阿斯娶了路得为妻，与她同房。耶和华使她怀孕生了一个儿子。……这俄备得是耶西的父，耶西是大卫的父。
（得 4:13-17）
```

在士师时代的黑暗背景下，路得记如同一缕曙光。它记载了摩押女子路得因着对婆婆拿俄米的爱和对以色列真神的投靠，来到伯利恒，并嫁给波阿斯，成为大卫的曾祖母，被列入耶稣的家谱。这显明神的救恩临到万邦。

路得记让我们看到，一个人能参与神的国度，不是借着血统和出身，而是借着信心和顺服。波阿斯作为赎业至亲，预表了基督——祂是我们至近的亲属，付上了生命的赎价，将我们从罪中赎回。是那位永远的君王、真正的救主，祂完全顺服，完全得胜，永远掌权。

## 二、君王时期（撒母耳记上下、列王纪上下、历代志上下）

### 《撒母耳记上下》——君王出场

- **关键词**：君王、国度、安息
- **主题**：神透过君王治理神的百姓，然而君王同时也是百姓的代表，君王的治理或者带来祝福，或者带来惩罚。

**核心经文：**

```text
你的家和你的国必在我面前永远坚立。你的国位也必坚定，直到永远。
（撒下 7:16）
```

```text
王住在自己宫中，耶和华使他安靖，不被四围的仇敌扰乱。那时，王对先知拿单说：“看哪，我住在香柏木的宫中，神的约柜反在幔子里。”拿单对王说：“你可以照你的心意而行，因为耶和华与你同在。”
（撒下 7:1-3）

我必为我民以色列选定一个地方，栽培他们，使他们住自己的地方，不再迁移；凶恶之子也不像从前扰害他们，并不像我命士师治理我民以色列的时候一样。我必使你安靖，不被一切仇敌扰乱。
（撒下 7:10-11）
```

撒母耳记是以色列从士师时代过渡到君主时代的历史，可以理解为以色列政治体制的转型，也就是从神权治理下的士师时代，过渡到君主制王国时代。百姓要求立王——他们想像列国一样。扫罗出场被立为王，却因不顺服而被废弃；大卫被膏立，成为合神心意的人。

撒母耳记围绕着撒母耳、扫罗和大卫展开：扫罗（以及后面很多类似他的君王）在这些顺服听命上失败，行耶和华眼中看为恶的事，但是神仍然是信实的。在撒母耳记下第七章是全书最重要的章节——神与大卫立约，应许他的后裔必永远坐在宝座上，并且建立了大卫的家谱。

大卫之约是神救赎计划的关键一步，从亚伯拉罕之约到西奈之约，再到大卫之约，神一步步启示祂要通过一个君王来祝福万国。

大卫成为全以色列的王，征服耶路撒冷，迎接约柜，神与他立下永恒之约。大卫是合神心意的人，但他也犯错，犯奸淫、杀人、数点百姓，显明即使是合神心意的王，也无法靠自己持守约。唯有那位永远的君王、真正的救主，祂完全顺服，完全得胜，永远掌权。

### 《列王纪上》——没有完美且永远的君王（王国分裂与被掳）

- **关键词**：统一到分裂、由盛（国家、圣殿）转衰
- **主题**：顺服蒙福，不顺服受咒诅，致使王国分裂与亡国

**核心经文：**

```text
你若效法你父大卫，存诚实正直的心行在我面前，遵行我一切所吩咐你的，谨守我的律例典章，我就必坚固你的国位在以色列中，直到永远，正如我应许你父大卫说：“你的子孙必不断人坐以色列的国位。”倘若你们和你们的子孙转去不跟从我，不守我指示你们的诫命律例，去事奉敬拜别神，我就必将以色列人从我赐给他们的地上剪除。
（王上 9:4-7）
```

列王纪上涵盖了约120年（主前971–853年），记述了统一王国从所罗门登基到王国分裂的过程。而评判他们的唯一标准是，他们是否行耶和华眼中看为正，还是恶。而唯有那位永远的君王、真正的救主，祂完全顺服，完全得胜，永远掌权。

### 《列王纪下》——在绝望中，指向完美永恒的君王，祂必来拯救

- **关键词**：背约而亡

**核心经文：**

```text
耶和华必使你们分散在万民中，从地这边到地那边，你必在那里侍奉你和你列祖素不认识木头石头的神。
（申命记 28:64 和合本）
```

```text
耶和华向以色列人大大发怒，从自己面前赶出他们……以致耶和华从自己面前赶出他们，正如藉他仆人众先知所说的。这样，以色列人从本地被掳到亚述。
（列王纪下 17:18-23 和合本）
```

列王纪写于被掳时期，记载了以色列王国的分裂和被掳。所罗门建造圣殿，王国达到顶峰；但他晚年被外邦妻子引诱去敬拜别神，导致王国分裂。北国以色列于主前722年被亚述所灭；南国犹大于主前586年被巴比伦摧毁，圣殿被焚，百姓被掳。

它解释以色列和犹大被掳的根本原因：带领以色列的君王，究竟是一个顺服、行耶和华眼中看为正的君王，以至于他们得着祝福；还是拥有了一个叛逆、行耶和华眼中看为恶的君王，以至于他们受苦。结果是他们背约，离弃耶和华，审判必临到。但神是信实的，祂守约施慈爱，并启示有一位永远的君王、真正的救主，祂完全顺服，完全得胜，永远掌权。

### 《历代志上下》——从亚当到大卫，从大卫到列王（大卫之约仍在继续）

- **关键词**：追溯、盼望
- **主题**：神仍与祂的百姓同在，成败完全取决于对神忠诚与否

**核心经文：**

```text
这称为我名下的子民，若是自卑、祷告，寻求我的面，转离他们的恶行，我必从天上垂听，赦免他们的罪，医治他们的地。
（代下 7:14）
```

列王纪是在被掳过程中所写的，主要是告诉以色列百姓：虽然神允许他们被掳，但是神并没有背约。对于历代志的作者来说，被掳已经结束了，所以他要提醒百姓神仍然是值得信靠的，神对他们仍有计划。所以历代志没有提到列王纪里一些重要的故事，却更关注列王纪所有没有提到的一些事情。它要强调、要告诉以色列百姓：约仍在继续，神仍守约施慈爱。

所以，列王纪要讲述的是神的百姓为什么会被掳，而历代志则要强调回来之后他们的盼望在哪里。它从不同的角度重述了以色列的历史，是要告诉他们，神仍然愿意与你们同在，他们的身份是神的子民，要归回圣殿，归回神，因此他们重返圣殿，重新归向祂。

最后，历代志以波斯王居鲁士下诏允许犹太人回归重建圣殿作为结尾，也为后面的以斯拉记作了伏笔和铺垫。如此环环相扣中，神的百姓仍有盼望。因为大卫的后裔仍然存留，对圣殿的焦点提醒神的百姓：神会坚立祂的国，也就是大卫后裔的国，直到永远。正如代下 21:7 所说的：耶和华却因自己与大卫所立的约，不肯灭大卫的家，照他所应许的，永远赐灯光与大卫和他的子孙。

将来有一位永远的君王、真正的救主，祂完全顺服，完全得胜，祂必来永远掌权。

## 三、被掳归回时期（以斯拉记、尼希米记、以斯帖记）

### 《以斯拉记》——重建圣殿

- **关键词**：归回、重建（圣殿、圣民）
- **主题**：神使百姓被掳回归重建圣殿

**核心经文：**

```text
波斯王居鲁士元年，耶和华为要应验藉耶利米口所说的话，就激动波斯王居鲁士的心，使他下诏通告全国。
（拉 1:1）
```

这是历代志的结尾，更是以斯拉记的开始。当他们在预言中被掳七十年后，神激动波斯王居鲁士的心，允许犹太人回归耶路撒冷重建圣殿。

因此第一批归回者踏上回归之路，重建圣殿。而重建神殿的重点不在于建筑本身，而在于恢复对真神耶和华的敬拜。以斯拉记记载了所罗巴伯带领第一次归回重建圣殿，以及以斯拉带领第二次归回带领百姓认罪悔改，重建圣民。这被掳者归回的应验，标志着神是信实守约的神。这些余民的归回与存留，更标志着神对大卫之约的保守。但此时有一个重要的悬念：大卫家的血脉还在、敬拜的圣殿还在，但地上的政权却缺席了，这迫使他们不得不去想——

神以此揭示：既然地上的宝座空缺，这个宝座一定不再是建立地上短暂的数十年王权，而是透过那位永远的君王、真正的救主——祂完全顺服，完全得胜，坐在大卫宝座上的耶稣基督——要建立一个属灵、永远掌权的永恒国度。

### 《尼希米记》——重建城墙

- **关键词**：重建（城墙）、归回
- **主题**：在艰难中依靠神，重建城墙

**核心经文：**

```text
然而我们祷告我们的神，又因他们的缘故，就派人看守，昼夜防备。
（尼 4:9）
```

尼希米记的核心不在于城墙本身，而在于重建保护圣约子民：他修城墙划定圣俗，恢复律法归正百姓的生活，处理罪恶以维护约的纯洁。

然而尼希米记仍暴露着缺憾：城墙虽修好，以色列却仍在波斯统治之下；百姓虽认罪立约，罪的根却未被拔出；当城建成，城中却没有百姓，大卫的宝座依然空着。

所以，尼希米能修复石头的城墙，却无法修复人心的破口；他能带领百姓离开巴比伦，却不能将人从罪的奴役中释放出来。因此尼希米记不是终点，他是搭好了舞台等待主角登场——就是那荣耀的君王，那位永远的君王、真正的救主，祂完全顺服，完全得胜，坐在大卫宝座上的耶稣基督，要建立一个属灵、永远掌权的永恒国度。

### 《以斯帖记》——暗中的保守

- **关键词**：翻转
- **主题**：神在暗中的护理与保守

**核心经文：**

```text
焉知你得了王后的位分，不是为现今的机会吗？
（斯 4:14）
```

以斯帖记是旧约中唯一没有提到神的名字，也没有提到大卫、弥赛亚。只用环境、际遇、人的选择暗中保守——带来翻转，挫败这场灭族阴谋，保全犹太百姓。即使我们看不见神，而神仍然在保守动工，祂永远掌权。

因为，若哈曼的阴谋一旦得逞，犹太人将彻底从这世上除名，包括已经归回的犹太百姓。也因此，那永远坐在大卫宝座上的这应许，将永远无法兑现，约将中断，一切都将终结、落空。所以，在如此奇妙的翻转中，显明唯有神！我们更加有理由相信等候：那位永远的君王、真正的救主，坐在大卫宝座上的耶稣基督，必完全顺服，完全得胜，祂要建立一个属灵、永远掌权的永恒国度，一切都已就绪，祂即将拉开帷幕。

1. 请问十二卷历史书，回顾下来，具体有收获（认知、记忆、感受、体会、意识、属灵、生活）？

2. 今天你对信主（耶稣是我的主，我的王），有什么更深的理解？
   （透过以上十二卷看到，一位完全、顺服的君王，是整个救赎的核心；一位君王的得胜与失败，行正或行恶，竟是直接决定着神的百姓生死、祝福与咒诅。这个问题一定要先讲解本课的核心，否则这题就发挥不出要提问的意义。）

3. 你到底是在信「一位主」，还是在信「一个能帮你解决问题的主」？在我们心中到底谁在做王掌权？
   （一种是能帮我的神，是我遇到难处时找祂，平时我自己说了算。另一种「一位主」，祂是我的掌权者，我人生的在祂手里，大事小事我停下来问「主，祢要我怎么做」。我们诚实看看自己，你跟神的关系，更像前者还是后者？如果是前者，那「信主」这两个字，对你来说到底意味着什么？一个灭亡的王，会带你一同灭亡；一位得胜的王，会带你一同得胜。因此我们要细细地品尝：耶稣是否在你心中掌权的重要。）

4. 可以细细想想，如何落实「让耶稣在我们心中掌权」？
