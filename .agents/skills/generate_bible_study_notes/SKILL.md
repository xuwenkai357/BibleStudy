# 目标
当用户要求基于某段查经录音、讲道或粗糙文字稿，来“生成查经文档”、“提炼大纲”或“整理笔记”时，严格触发此技能，输出三份高质量、标准化的 Markdown 文档。

# 文档输出规范 (核心交付物)
必须利用获取到的原文，输出以下三份固定格式的文档（文件需保存在对应经卷目录中）：

1. **[查经书卷名]_01_结构化查经大纲.md**
   - **定位**：带组查经的白板大纲或备课思维导图。
   - **内容要求**：宏观脉络提炼，必须包含：查经背景、章节结构拆解、核心探讨点。
   - **排版**：使用清晰的 Markdown 列表、小标题。

2. **[查经书卷名]_02_全维度典藏版.md**
   - **定位**：最高质量的实战带领及导读手册。
   - **内容要求**：
     - **核心摘要 (Executive Summary)**：简短有力地总结本次查经的精髓。
     - **结构化大纲与深度见解 (Structured Outline & Insights)**：不能仅仅停留在历史复述，必须有拔高的生命应用及深层神学含义。
     - **带组查经实用指南 (Facilitator's Tips)**：给出2-3个能直击人心的破冰或引导问题。
   - **排版要求**：必须注重美感。使用 Quote (`>`) 来强调箴言，适度加入相关的 Emoji（如 🌟、📖、💡）以增加现代感与阅读体验。

3. **[查经书卷名]_03_纯净版逐字稿.md**
   - **定位**：原汁原味的感动保留。
   - **内容要求**：智能清除无意义的语气词和口吃停顿。准确识别并按顺序标注不同发言人的名字。严格按逻辑和语意自然分段。

# 核心执行流
1. **确认先决条件**：如果是从媒体文件开始，确保音频已经通过 `parse_large_audio` 技能处理完毕，且你已经能看到带有时间戳的原始文本。
2. **确认用户参数**：分析用户的需求提示，必须提取并结合以下三点来定调：
   - 核心发言人/主领人是谁？
   - 目标受众群体是谁（如慕道友、初信徒、成熟信徒）？
   - 查经的核心侧重主题是什么？
3. **分批生成与保存**：调用写文件工具，将上述三份不同维度的文档依次准确地写入到对应文件夹中。完成前不要随意略过细节。
