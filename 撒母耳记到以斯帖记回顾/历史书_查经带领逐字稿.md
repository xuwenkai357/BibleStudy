# 旧约历史书回顾（约书亚记至以斯帖记）带领逐字稿

## 带领说明：
本稿件设计为**高频互动式带领**，旨在打破“台上讲、台下听”的单向输出。对象为**成熟信徒与小组长**。
- **第一部分（约50分钟）**：承上启下接续摩西五经复习；**先花约8–10分钟，让大家简单拾起从约书亚记到以斯帖记的故事线**（只唤醒记忆，不讲神学）；再讲清「历史书的钥匙」（大卫之约 / 君王 / 太1）；再按三个时期带着钥匙**把每卷内部讲解讲透**（取自丰富版，不要缩成提纲）。每卷含关键词、主题、内容分段、核心经文与🔗小结。
- **第二部分（约30–40分钟）**：四个深度问题，进入生命反思。尤其问题2、3——提问前**必须先讲解**括号批注与「基督掌权」落脚点。
- 所有核心经文已使用代码块框出，请在现场邀请家人**大声朗读**。
- 语气：温暖「家人们」、第一人称「我」、神学谨慎、经文用和合本。

## 第一部分：承上启下 + 故事拾忆 + 钥匙 + 十二卷回顾（约50分钟）

**【开场白 · 承上启下】**
**我：**“家人们好！上次我们一起复习了摩西五经。还记得我们当时提炼出来的那个关键词吗？”

*（互动预留：约。）*

**我：**“对，就是『约』。摩西五经是应许的起点——神说：『我要作你们的神，你们要作我的子民。』神拣选亚伯拉罕，从埃及救出百姓，在西奈山立约，赐下律法。整本摩西五经都在告诉我们：人都是罪人，人没有办法靠自己对付自己的罪；但神的恩典之约永远长存，呼唤那位能赐新心的完美救主。

今天我们往下走，进入旧约历史书——从约书亚记到以斯帖记，一共十二卷。关键词**仍然是『约』**，但焦点推进了一步：从『应许的起点』，到『应许的展开与持守』——从亚伯拉罕之约到大卫之约，最终指向永远的君王基督。摩西五经与历史书，在神的救赎计划里是衔接的、环环相扣的、递进的——两个至关重要的节点。”

**【互动提问：历史书给人什么印象？】**
**我：**“大家回想一下，读约书亚到以斯帖这段历史，最容易给人什么印象？战争？王朝兴衰？还是觉得神好像很严厉？”

*（互动预留：请家人简短说。）*

**我：**“是的，很容易只看见战争、政治、被掳，甚至误解神残暴、毫无仁慈。这段近千年的历史，始于约书亚攻取迦南，到被掳巴比伦归回，意味着旧约时代即将结束。当我们开始学习这段历史时，是否能拨开云雾，真正看见背后上帝的心意？

历史书让我们看见两件事：**神的信实，与人的败坏。** 以色列人纵然失信，神却总是信实的。顺服蒙福、悖逆遭咒——这条守约的原则没有变；只是进到历史书，它更常透过君王的『行正 / 行恶』显明在全国的命运上。

不过钥匙我先不急着交。十二卷跨了将近一千年，很多人记得几个人名、几场仗，整条故事线却糊了。我们先花几分钟，把从约书亚记到以斯帖记的故事捡起来——每卷发生了什么、谁出场了。故事在手里，钥匙才打得开。”

**【故事拾忆】先把十二卷的故事线捡起来（约8–10分钟）**

**带领说明：** 此环节只做「记忆唤醒」，不讲神学、不交钥匙。可用接龙：一卷一人，说一两句即可；冷场时带领者用下面话术补上。目标是让家人重新摸到每卷书的情节与人物。

**我：**“家人们，我们接龙。每卷用一两句话：发生了什么？谁出场了？我先起个头——摩西五经结束时，百姓还站在约旦河东。下一卷是谁接棒？”

*（互动预留：约书亚 / 过河、打仗、分地。）*

**征服与士师时期（约书亚记、士师记、路得记）**

**我：**“对。《约书亚记》：摩西死后，约书亚领百姓过约旦河，攻下耶利哥，南征北战，把地分给十二支派，百姓进入安息。故事不再是旷野漂流，而是进入、得着。

约书亚死后呢？大家还记得《士师记》的味道吗？”

*（互动预留：乱 / 循环 / 没有王 / 各人任意而行。）*

**我：**“《士师记》：百姓离弃神、被外邦欺压、呼求、神兴起士师拯救、和平一阵、再犯罪——这个循环重复了九次，而且越来越糟。底下一句话：那时以色列中没有王，各人任意而行。

黑暗里还有一卷很短的书——《路得记》。还记得路得是谁吗？”

*（互动预留：摩押女子 / 跟随拿俄米 / 嫁波阿斯 / 大卫的曾祖母。）*

**我：**“对。路得跟着婆婆拿俄米回伯利恒，嫁给波阿斯，生下俄备得——耶西的父，大卫的父。士师时代里的一缕光，大卫家的故事从这里埋下种子。”

**君王时期（撒母耳记、列王纪、历代志）**

**我：**“然后百姓开口要什么？”

*（互动预留：要王 / 像列国一样。）*

**我：**“《撒母耳记上下》：撒母耳膏立扫罗为王；扫罗不听命被废；大卫被膏，统一全国，定都耶路撒冷，迎接约柜。神与大卫立约。可大卫自己也犯罪——拔示巴、乌利亚、数点百姓。合神心意的王，故事里也有深深的裂痕。

大卫之后是谁？王国后来怎么了？”

*（互动预留：所罗门 / 建圣殿 / 分裂 / 被掳。）*

**我：**“《列王纪上下》：所罗门建圣殿，国势到顶峰；晚年拜偶像，死后王国裂成北国以色列、南国犹大。北国主前722年亡于亚述，南国主前586年亡于巴比伦——圣殿被烧，百姓被掳。一卷书记了从盛到衰、从统一到亡国。

还有两卷《历代志上下》，故事听起来跟列王纪好像重复。其实角度不同：写给已经归回的人，从亚当追溯到大卫、到列王，要告诉他们——盼望还在，约还在。”

**被掳归回时期（以斯拉记、尼希米记、以斯帖记）**

**我：**“被掳七十年后，谁让他们回家的？”

*（互动预留：波斯王居鲁士 / 所罗巴伯 / 以斯拉。）*

**我：**“《以斯拉记》：波斯王居鲁士下诏，所罗巴伯带第一批归回，重建圣殿；以斯拉带第二批，读律法、带百姓认罪——重建的是圣民。殿起来了，城还破着。谁来了？”

*（互动预留：尼希米。）*

**我：**“《尼希米记》：尼希米从波斯回来修耶路撒冷城墙，五十二天完工，又带百姓守律法、重新立约。石头墙修好了，人心的破口却还在。

还有一卷，发生在没回家、仍散在外邦的犹太人中间——《以斯帖记》。还记得哈曼吗？”

*（互动预留：灭族阴谋 / 以斯帖、末底改 / 翻转 / 普珥日。）*

**我：**“对。波斯宫廷里，哈曼要灭尽犹太人；以斯帖、末底改被兴起，阴谋翻转，后来有了普珥日。这卷书甚至没提神的名字，故事却整个翻过来了。

家人们，故事线捡起来了吗？从进迦南，到乱世、立王、建国、分裂、亡国、归回——将近一千年，十二卷，一条线。好，故事在手里了，现在我才把钥匙交出来——没有故事，钥匙是空的；没有钥匙，故事只是流水账。”

**【钥匙教学】历史书的一把钥匙（务必先讲清）**

**我：**“故事线捡起来了。现在，我要把一把『钥匙』交到大家手里。没有这把钥匙，十二卷书容易变成流水账；有了它，整部历史书就活了。

**第一，整部历史书的核心，是大卫之约。** 请大家一起读：”

```text
【撒母耳记下 7:16】
你的家和你的国必在我面前永远坚立。你的国位也必坚定，直到永远。
```

**我：**“神应许大卫：他的后裔要永远坐在宝座上。整部历史书——从约书亚进迦南，到被掳归回——都在绕着这把钥匙转。

**第二，焦点落在『君王』。** 地上没有一位君王是完美的、超越的、可以永远掌权的。扫罗失败，大卫也会犯罪，所罗门晚年拜偶像，列王大多行恶。历史一再证明：人没法靠自己成全；人最终没法把自己从罪恶里救出来。讲义从头到尾其实在说一件事——**上帝要建立一个国度，但这国度一直缺一位完美、永不失败、永远掌权的君王。**

**第三，模式变了。** 上次申命记里，神是直接对百姓说：顺服蒙福，悖逆遭咒诅。进到历史书，神开始**透过君王**来管理、代理、代表以色列百姓。君王『行耶和华眼中看为正』，国家蒙福；君王『行恶』，就直接导致衰败、分裂、被掳。君王选对了没有，对百姓是生死攸关的事。

**第四，新约一开卷就接上这把钥匙。** 请读：”

```text
【马太福音 1:1】
亚伯拉罕的后裔，大卫的子孙，耶稣基督的家谱。
```

**我：**“耶稣是亚伯拉罕的后裔、大卫的子孙——弥赛亚、完美君王。这把钥匙既解开摩西五经，也解开历史书。今天回顾的落脚点很清楚：**让基督这位完美君王在我们生命中掌权。顺服基督就是顺服神；在基督里就蒙福、得蒙喜悦；在基督以外、不被掌权，就是亏损。**

好，抓住钥匙，我们按三个时期再走一遍。情节前面已经捡过，这一遍要把每卷内部的讲解讲透——核心经文、神学扣回、钥匙回响，不要再缩成提纲。”

**一、征服与士师时期（约书亚记、士师记、路得记）**

### 1. 《约书亚记》——进入应许之地（得着应许）
- **关键词**：土地、征战、安息
- **主题**：神信实守约，带信靠祂的以色列人进入迦南、征服迦南，并且进入安息。
- **内容分段**：
  - 1–5章：承接摩西，过约旦河，进入应许之地
  - 6–12章：征战得地（神已经得胜，百姓凭信心领受）
  - 13–22章：分地承受产业
  - 23–24章：约书亚临终劝勉，重新坚立圣约

**我：**“摩西五经结束时，百姓还站在约旦河东。历史书一开篇，神就信实地把『土地』的应许往前推。约书亚记是救恩历史的全新篇章——**不再是关于漂流，而是关于承接与得着。** 摩西死后，神呼召约书亚起来，带领百姓过约旦河、进入迦南。约书亚这名字是什么意思？”

*（互动预留：耶和华是拯救 / 预表耶稣。）*

**我：**“对！原意是『耶和华是拯救』，希腊文形式就是『耶稣』——他预表那一位真正的拯救者。这卷书的核心不再是『我们会不会失败』，而是『神已经为我们得胜，好叫我们凭信心去领受』。请大家读核心经文：”

```text
【约书亚记 1:3】
凡你们脚掌所踏之地，我都照着我所应许摩西的话赐给你们了。
```

```text
【约书亚记 1:16-17】
他们回答约书亚说：“你所吩咐我们行的，我们都必行；你所差遣我们去的，我们都必去。我们从前在一切事上怎样听从摩西，现在也必照样听从你。惟愿耶和华你的神与你同在，像与摩西同在一样。”
```

**我：**“看见没有？约没有断。摩西五经末了，百姓站在河边；历史书开篇，神信实成就对亚伯拉罕、以撒、雅各、摩西的『土地』应许。百姓说：从前怎样听从摩西，现在也必照样听从你——承接的是同一位守约的神。应许在展开。”

> 🔗 **【总结：《约书亚记》与「约」】**
> 应许中的「土地」开始兑现。神信实守约，把漂流的百姓带进安息；约书亚预表真正的拯救者基督。

### 2. 《士师记》——没有王
- **关键词**：循环、悖逆、拯救
- **主题**：离开神带来败坏与压迫；神的百姓需要一位完全的拯救者，方能保护这土地、得到安息。
- **内容分段**：
  - 1–2章：约书亚死后，征服未竟，百姓离弃神
  - 3–16章：九次循环（犯罪—压迫—呼求—士师拯救—再犯罪），且越来越糟
  - 17–21章：道德沦丧的黑暗——没有王，各人任意而行

**我：**“进了迦南，分了地，然后呢？约书亚死后，以色列人陷入拜偶像、道德沦丧的黑暗时代。他们离弃神，被仇敌欺压；苦难中呼求，神就兴起士师拯救；士师一死，他们又犯罪远离神。这卷书暴露的，是人内心的罪恶，和对救赎主的迫切需要。士师记用一句话总结自己，大家还记得吗？”

*（互动预留：那时以色列中没有王，各人任意而行。）*

```text
【士师记 21:25】
那时以色列中没有王，各人任意而行。
```

**我：**“犯罪—神允许外敌压迫—百姓悔改呼求—神兴起士师拯救—恢复和平—再次犯罪。这个循环在整卷里重复了九次。家人们，这九次是一样的吗？”

*（互动预留：不是 / 越来越糟 / 胜利越来越小。）*

**我：**“对，是越来越糟糕的循环。随着整卷书往前走，每一个士师所获得的胜利也越来越小。摩西和约书亚生前早已预言这一幕——人若离开神，在罪中只会越陷越深。每一次拯救之后，他们又回到老路上。这说明什么？”

*（互动预留：人靠自己对付不了罪 / 需要永远的君王。）*

**我：**“对。人靠自己根本没有办法对付自己的罪。我们需要的不只是一个又一个临时的士师，而是一位永远的君王、真正的救主——完全顺服、完全得胜、永远掌权。钥匙在这里已经在响：国度有了土地和百姓，却『没有王』——完美君王的缺席，成了全书的呼喊。”

> 🔗 **【总结：《士师记》与「约」】**
> 百姓违约，循环坠落；「没有王」的呼喊，把我们推向大卫之约与基督。

### 3. 《路得记》——伏笔应许中的王
- **关键词**：跟随、忠诚
- **主题**：神奇妙的救赎计划，在黑暗中埋下种子。
- **内容分段**：
  - 1章：路得因爱与信心，跟随拿俄米回伯利恒
  - 2–3章：波阿斯以恩慈接待，显出赎业至亲的责任
  - 4章：波阿斯娶路得，家谱接到大卫——伏笔永远的君王

**我：**“士师时代的黑暗里，路得记如同一缕曙光。一位摩押女子，因着对婆婆拿俄米的爱，和对以色列真神的投靠，说：”

```text
【路得记 1:16】
不要催我回去不跟随你。你往哪里去，我也往那里去；你在哪里住宿，我也在那里住宿；你的国就是我的国，你的神就是我的神。
```

**我：**“路得来到伯利恒，嫁给波阿斯，成为大卫的曾祖母，被列入耶稣的家谱。家人们，一个外邦女子怎么能进弥赛亚的家谱？这卷书要告诉我们什么？”

*（互动预留：信心和顺服 / 救恩临到万邦 / 不是靠血统。）*

**我：**“对。一个人能参与神的国度，不是借着血统和出身，而是借着信心和顺服。波阿斯作为赎业至亲，预表基督——祂是我们至近的亲属，付上生命的赎价，将我们从罪中赎回。神的救恩临到万邦，大卫之约的伏笔已经写下。请读家谱的落点：”

```text
【路得记 4:13-17】
于是，波阿斯娶了路得为妻，与她同房。耶和华使她怀孕生了一个儿子。……这俄备得是耶西的父，耶西是大卫的父。
```

> 🔗 **【总结：《路得记》与「约」】**
> 在违约的黑暗中，神用信心与忠诚埋下大卫家谱的种子，指向永远的君王。

**二、君王时期（撒母耳记上下、列王纪上下、历代志上下）**

### 4. 《撒母耳记上下》——君王出场（枢纽！）
- **关键词**：君王、国度、安息
- **主题**：神透过君王治理百姓；君王同时也是百姓的代表——治理或带来祝福，或带来惩罚。
- **内容分段**：

```text
【列王纪下 17:18-23】
```

**我：**“它解释以色列和犹大被掳的根本原因：带领百姓的君王，究竟是一个顺服、行耶和华眼中看为正的君王，以至于他们得着祝福；还是一个叛逆、行耶和华眼中看为恶的君王，以至于他们受苦。结果是他们背约，离弃耶和华，审判必临到。

看见模式转变了吗？申命记是直接对百姓说祝福咒诅；历史书是透过君王的行正/行恶，把祝福或咒诅临到全国。一个悖逆的君王，给百姓带来极大亏损。但神是信实的，祂守约施慈爱，并启示有一位永远的君王、真正的救主——祂完全顺服，完全得胜，永远掌权。”

### 问题 2：信主 = 认耶稣是我的主、我的王？（🔥先讲核心再问）
**【问题】**：今天你对信主（耶稣是我的主，我的王），有什么更深的理解？
**【引导方向】**：**务必先讲解本课核心**，否则此题发挥不出意义。要点：一位完全、顺服的君王是救赎核心；君王的得胜/失败、行正/行恶，直接决定百姓生死、祝福与咒诅；历史书模式是神借君王代表百姓——今日认耶稣为主，就是认祂为生命掌权的王。
**【带领话术示范】**：“家人们，提问前我先把核心讲透。十二卷历史书不是要我们学古代政治，而是让我们看见：谁在做王，谁就决定一群人的命运。扫罗一悖逆，连累百姓；大卫一犯罪，刀剑不离他家；后来列王行恶，整个国家分裂、被掳。反过来，一位行正的君王，能带百姓蒙福。

所以『信主』这两个字，绝不是『我信有一位神存在』，而是『耶稣是我的主，我的王』——主权在祂。太1说祂是亚伯拉罕的后裔、大卫的子孙，就是那位完美君王。今天问大家：你对『信主』这两个字，有什么更深的理解？祂真是你的王吗？”
**【回答示例（供带领者参考）】**：
*   “以前『信主』对我是得救上天堂；今天才意识到，更是把宝座交出去——让祂决定我的方向。”
*   “我发现我常说耶稣是主，但重大决定其实是自己拍板，祂更像顾问。历史书让我害怕：错的王会带人灭亡。”

### 问题 3：信「一位主」，还是信「能解决问题的主」？（🔥核心击穿点）
**【问题】**：你到底是在信「一位主」，还是在信「一个能帮你解决问题的主」？在我们心中到底谁在做王掌权？
**【深度分析】**：两种信仰形态——
1. **能帮我的神**：遇难处才找祂，平时自己说了算。
2. **一位主**：祂是掌权者，人生在祂手里，大事小事停下来问：「主，祢要我怎么做？」
**【带领话术示范】**：“家人们，这个问题很锋利，我们诚实面对。一种关系像急救电话——疼了才拨打，平时我自己当老板。另一种关系是君臣、是圣约——祂说了算，我问祂要我怎么做。

历史书已经告诉我们：一个灭亡的王，会带你一同灭亡；一位得胜的王，会带你一同得胜。**顺服基督就是顺服神；在基督里就蒙福、得蒙喜悦；若在基督以外、不被基督掌权，就是亏损。** 你跟神的关系，更像前者还是后者？如果是前者，『信主』对你到底意味着什么？耶稣有没有在你心中掌权？”
**【回答示例（供带领者参考）】**：
*   “我真实是前者。工作出问题才拼命祷告；一顺利，一周都不问主。我信的是『能解决问题的主』，不是『一位主』。”
*   “我服侍很忙，但心中宝座是『效率』和『别人的评价』。历史书里的空宝座，像在问我：你的宝座上坐的是谁？”

### 问题 4：如何落实「让耶稣在心中掌权」？（落地应用）
**【问题】**：可以细细想想，如何落实「让耶稣在我们心中掌权」？
**【引导方向】**：从认知转到可操作的回应；可连结「行正/行恶」到每日选择；避免只停留口号。
**【带领话术示范】**：“今天钥匙已经交到我们手里：万王之王、万主之主，超越时空、胜过罪恶的耶稣基督。回应祂，不能只停在『我明白了』。落实掌权，可以很具体——比如：做决定前先问主；认罪时不自己当法官；金钱、关系、服侍上谁说了算；把『行耶和华眼中看为正』从列王身上转到今天的选择。家人们，这一周你愿意在哪一件具体的事上，把宝座让给祂？”
**【回答示例（供带领者参考）】**：
*   “我愿意在财务上不再自己先定计划再求神盖章，而是先问：『主，这笔钱祢要我怎么用？』”
*   “我跟家人起冲突时，习惯自己当王、定对错。我愿意先停下来祷告，再开口——让祂掌权，而不是让怒气掌权。”
